# Architecture Decision Records

Este diretório registra decisões arquiteturais e de produto duradouras do Streamlet.

## Convenção

- Nome: `NNNN-titulo-curto-em-kebab-case.md`.
- Status permitido: `proposta`, `aceita`, `substituída` ou `rejeitada`.
- Uma decisão aceita não deve ser reescrita para esconder o histórico. Quando mudar, criar outro ADR e indicar qual documento foi substituído.
- Cada ADR deve apontar para as seções afetadas da especificação e para as batches relacionadas.
- Consequências, riscos e plano de reversão devem ser concretos.

Copie [0000-template.md](./0000-template.md) para iniciar uma decisão.
